# Simonator voor Android

Jouw muziek, op jouw speler.

## Downloaden

**[Download de nieuwste APK](https://github.com/vennesch/Simonator-downloads/releases/latest/download/Simonator.apk)**

[Bekijk de releasenotes en eerdere versies](https://github.com/vennesch/Simonator-downloads/releases)

Je kunt deze downloadlink met anderen delen. Een GitHub-account is niet nodig.

## Installeren

1. Open de downloadlink op je Android-telefoon.
2. Open `Simonator.apk` en sta, wanneer Android daarom vraagt, installatie vanuit je browser toe.
3. Staat Simonator al op je telefoon? Installeer de update eroverheen. Verwijder de bestaande app niet.
4. Nieuwe gebruiker? Volg de kennismaking in Simonator en meld je aan met je eigen Qobuz-account.

Deze APK is voor Android-telefoons met een ARM64-processor, vanaf Android 7.0.

Deze repository bevat alleen downloads en releasenotes. De ontwikkelrepository is privé.
